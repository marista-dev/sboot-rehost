# ⚠ 이 명령은 폐기됐습니다 (v0.21.0)

`rehost-setup` 은 펌웨어별 워크스페이스 생성 명령 이었습니다. **v0.21.0 에서 `/sboot-rehost:start` 하나로 합쳐졌습니다.**

폴더 생성 · 의존성 설치 · 펌웨어 인식 · 워크스페이스 생성 · 실행이 각각 사용자 결정을
요구해서 나뉘어 있었는데, 지금은 전부 상태에서 도출되므로 가를 이유가 없습니다.

## 대신 쓸 것

```
/sboot-rehost:start [F1|F2|F3]
```

| 상황 | `start` 의 동작 |
|---|---|
| 처음 실행 | 작업 폴더를 만들고 `_inbox/` 에 펌웨어를 넣으라고 안내 후 종료 |
| 펌웨어를 넣은 뒤 | 인식 → 워크스페이스 → 도출 → 빌드 → 회차 루프 → 검증까지 자율 진행 |
| 이미 워크스페이스가 있음 | 이어서 진행 (재개) |

등급은 인자로만 받고 기본값은 `F2` 입니다.

## 이 명령은 아무것도 실행하지 않습니다

파이프라인을 호출하지 마십시오. 위 안내만 출력하고 종료합니다.
